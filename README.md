# ProductManager

Sistema web de gestión de productos desarrollado como proyecto académico de Programación III en el ITLA, aplicando Git y Git Flow para el control de versiones.

## Funcionalidades

- Registrar productos.
- Consultar el listado de productos.
- Editar productos existentes.
- Eliminar productos.
- Buscar productos por nombre.
- Validar los datos de los formularios.

## Tecnologías utilizadas

- C#
- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- SQLite
- Bootstrap
- Git y GitHub

## Estrategia de Git Flow

El proyecto utiliza una adaptación de Git Flow con tres ramas principales.

| Rama | Propósito |
|---|---|
| main | Versión estable del proyecto |
| dev | Integración de funcionalidades |
| qa | Pruebas y validación |

### Ramas desarrolladas

| Rama | Funcionalidad |
|---|---|
| feature/create-product | Registro de productos |
| feature/list-products | Listado de productos |
| feature/edit-product | Edición de productos |
| feature/delete-product | Eliminación de productos |
| feature/search-products | Búsqueda de productos |
| hotfix/fix-crud | Correcciones del CRUD |
